은방울꽃 × 린 — 중앙 동영상 홈페이지

파일:
- index.html : 홈페이지
- background.jpg : 제공한 배경 이미지
- video.mp4 : 사용자가 넣을 동영상 파일

사용:
1. ZIP 압축을 풉니다.
2. MP4 영상을 같은 폴더에 넣고 파일명을 video.mp4로 바꿉니다.
3. index.html을 브라우저에서 열어 미리 확인합니다.
4. 인터넷에 공개할 때 index.html, background.jpg, video.mp4를 모두 함께 업로드합니다.

참고:
배경은 화면 전체를 채우며, 화면 비율이 이미지와 다르면 가장자리가 일부 잘릴 수 있습니다.
영상이 100~200MB라면 호스팅 업로드 제한과 데이터 전송량을 확인하세요. 필요하면 동영상을 외부 스트리밍 서비스로 연결할 수 있습니다.
